
    <p>🇮🇹 <strong>Italiano</strong></p>

    <h3>Informativa sulla Privacy</h3>

    <p><strong>DragonSoftwarePass</strong> raccoglie e memorizza alcune informazioni degli utenti, tra cui password,
  note personali e token di sessione (bearer token).</p>

    <ul>
      <li>I dati sensibili vengono trasmessi al server backend e salvati criptati su database.</li>
      <li>Il token di sessione viene salvato localmente sul dispositivo per mantenere l’accesso dell’utente.</li>
      <li>Nessun dato viene condiviso con terze parti.</li>
      <li>Non vengono effettuate analisi, tracciamenti o invii di informazioni non necessari al funzionamento
  dell’estensione.</li>
    </ul>

    <p>In caso di modifiche future a questa politica, gli utenti saranno informati tramite aggiornamento della
  presente pagina.</p>

    <p>🇬🇧 <strong>English</strong></p>

    <h3>Privacy Policy</h3>

    <p><strong>DragonSoftwarePass</strong> collects and stores certain user information, including passwords,
  personal notes, and session tokens (bearer tokens).</p>

    <ul>
      <li>Sensitive data is transmitted to the backend server and stored encrypted in the database.</li>
      <li>Session tokens are stored locally on the device to maintain user login sessions.</li>
      <li>No data is shared with third parties.</li>
      <li>No analytics, tracking, or unnecessary data transmissions are performed beyond what is required for the
  extension’s functionality.</li>
    </ul>

    <p>Users will be informed of any changes to this policy through updates to this page.</p>
